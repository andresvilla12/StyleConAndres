## 📌 Descripción

**StyleConAndrés** es una tienda online moderna e innovadora desarrollada con Angular, dedicada a ofrecer ropa, accesorios, electrónica, muebles y zapatos para todas las ocasiones. El proyecto consume una API REST pública (Platzi Fake Store API) para mostrar productos reales con imágenes, precios y categorías.

## 🚀 Tecnologías utilizadas

- **Angular 17+** — Framework principal con componentes standalone y signals
- **TypeScript** — Lenguaje de programación tipado
- **Tailwind CSS** — Framework de estilos utilitarios
- **WaveSurfer.js** — Reproductor de audio con visualización de ondas
- **date-fns** — Librería para manejo de fechas
- **Platzi Fake Store API** — API REST pública para productos y categorías
- **Netlify** — Plataforma de despliegue

---

## ✨ Funcionalidades

- 🗂️ **Categorías filtradas** en español con emojis (Ropa, Electrónica, Muebles, Zapatos, Miscelánea)
- 🛒 **Carrito de compras** con agregar, eliminar productos y vaciar carrito
- 💰 **Precios formateados** en pesos colombianos
- ✅ **Disponibilidad** de productos en tiempo real
- 🖼️ **Placeholder de imagen** con logo de la marca cuando el producto no tiene foto
- 📱 **Página About** con misión, visión, valores corporativos y mensaje de bienvenida en audio
- 🔗 **Contacto** vía LinkedIn, Email y WhatsApp
- 📲 **Diseño responsivo** con fondo gradiente y estilo moderno

## 🛠️ Instalación y uso

```bash
# Clonar el repositorio
git clone https://github.com/andresvilla12/StyleConAndres.git

# Entrar al directorio
cd StyleConAndres

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npx ng serve

# Compilar para producción
npx ng build
```
